# Cognitive Mirror — product context

**What it is.** Capability intelligence for workplace learning. Each person
has two readings per capability:

- **Knows:** assessments and e-learns.
- **Does:** workplace evidence that a manager has validated.

Only the second reading moves a level. AI reviews evidence against an
approved rubric, but a manager decides, and every state change is audited.

**Who uses it.**

- **Learners** follow a journey (learn, check, apply at work) and submit
  evidence.
- **Managers** validate evidence and see their team's distribution. They
  never see an average.
- **Admins** govern the approved corpus, the rubric and the required levels.

**Surfaces and modes.**

- Sign-in: Persuade, kept light.
- Learner, manager and admin workspaces: Operate.
- Rubric clause popovers and the audit trail: Read.

**Tone.** Calm, encouraging and exact. The interface should make people want
to learn: clean, lively and in harmony, never alarming or gamified. Copy
states facts the backend computed and never inflates them.

**Constraints.**

- Demo tenant `apex-demo`.
- Quick test access (Learner / Manager / Admin) appears only in development
  with demo mode on.
- New Google accounts start as learners.
